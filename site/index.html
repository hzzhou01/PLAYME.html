Don’t just README. PLAYME.

PLAYME turns your paper or project (code, docs, run logs) into one interactive page. Readers operate your project’s mechanisms instead of reading about them, and every number still matches your paper or docs.

Why now

Interactive explanations were always better. They were just too expensive.

2011

Bret Victor proposes explorable explanations: text the reader can play with.

worrydream.com
2021

Distill pauses. Its editors: …the primary bottleneck is the amount of effort it takes to produce these articles…

distill.pub/2021/distill-hiatus
2026

A coding agent can now carry that effort, and PLAYME supplies the design rules. With PLAYME, Claude Code had the OpenGCUA lab’s first preview ready about four hours after the brief.

Case · OpenGCUA

A real research project, made playable

PLAYME made the project page of OpenGCUA, a computer-use agent research project, interactive. Claude Code built its interactive lab with PLAYME in one session while the paper’s authors reviewed each preview.

7labs, from a 3D teardown of a Mac to real runs
18playable parts, each with a progress bar
28author requests over 7 review rounds
1offline HTML file, English and Chinese
Install

Give your project a PLAYME

Claude Code
# one step (Claude Code 2.1.275 or later)
> /plugin install playme --marketplace hzzhou01/PLAYME.html
# or: add the marketplace, then install
> /plugin marketplace add hzzhou01/PLAYME.html
> /plugin install playme@playme
# or copy the skill folder
$ git clone https://github.com/hzzhou01/PLAYME.html
$ cp -r PLAYME.html/skills/playme ~/.claude/skills/
Needs Claude Code and Python 3. The checks also use Node and Chrome.
