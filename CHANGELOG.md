# Changelog

## 1.0.0 (2026-10-20)

First public version. Works from a paper or, for a project without one, from its code and docs.

- Skill: workflow, 18 rules, reader budgets; references for patterns, review loop, fidelity, words, visual identity,
  kit API, shipping and promotion.
- Kit: part template, player on a virtual clock with a scrubbable progress bar, code pane, folds, readouts, device
  frames (Mac, browser, phone, terminal), exploded 3D view on three.js r160.
- Scripts: `bundle.py`, `lint.mjs`, `fidelity.py`, `capture.mjs`.
- Homepage built with the kit (English and Chinese): five playable labs, a case section and install guide.
- Examples: the bundled starter, and a three-part PLAYME built blind for a toy caching paper.
- Case study: the OpenGCUA Interactive Lab, built with PLAYME (7 labs, 18 playable parts, 7 author review rounds).
